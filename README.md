# PhishGuard ML - URL Security

A machine learning-based phishing URL detection system that analyzes website URLs and predicts whether they are **Safe** or **Phishing**.

## 🚀 Project Overview

PhishGuard ML is a cybersecurity-focused machine learning project designed to help identify potentially malicious URLs.

The system extracts numerical features from a URL and uses a trained **Random Forest machine learning model** to classify the URL.
